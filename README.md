# 午饭随机吃什么 🍜

一个帮你在工作日中午快速决定吃什么的小工具。

## 功能

- 老虎机式滚动抽取，阻尼减速定住结果
- 内置 7 大品类共 70 道菜：中式快餐、面食、米饭套餐、汤粥、轻食沙拉、粉面、小吃
- 品类筛选：勾选想吃的类别，只在这些类别里抽
- 自定义菜品：随时添加自己的常吃菜，自动查重
- 删除菜品：内置菜品删除后可一键恢复默认
- 抽取记录：保留最近 5 次抽到的结果
- 深色模式：跟随系统，也可手动切换
- 本地存储：自定义菜品与偏好保存在浏览器 localStorage，不上传任何数据
- 移动端友好：适配刘海屏安全区，长菜名自动缩放

## 使用

直接用浏览器打开 `index.html` 即可，无需安装、无需联网。

在线版：https://licong0630-bit.github.io/lunch-randomizer/

## 技术说明

单文件纯静态页面，HTML + CSS + 原生 JS，零外部依赖、零构建步骤、无网络请求。
